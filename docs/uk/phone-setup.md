# Налаштувати телефон один раз

Українська · [Русский](../ru/phone-setup.md) · [English](../en/phone-setup.md)

Потрібні Android-телефон та інтернет. Комп’ютер не потрібен. Якщо Codex уже працює й бачить скіл `suno-tiktok-video`, перейдіть до [створення відео](first-video.md).

**Як виконувати кроки:** скопіюйте текст із сірого блоку, затисніть екран у потрібному застосунку → **Вставити** → **Enter**. Дочекайтеся завершення. Лише потім переходьте далі.

Якщо бачите запит `Do you want to continue? [Y/n]`, введіть `y` і натисніть Enter, щоб продовжити встановлення. Якщо з’явилась помилка або незрозумілий запит про заміну файлів — зупиніться й відкрийте [допомогу](help.md).

## 1. Встановіть Termux

Termux — застосунок, у який ви вставлятимете команди нижче.

1. Відкрийте [сторінку завантаження Termux](https://f-droid.org/en/packages/com.termux/).
2. Знайдіть **Download APK**, завантажте й відкрийте файл. Встановлювати сам F-Droid не обов’язково.
3. Якщо Android попросить дозвіл встановити застосунок із браузера — дозвольте це встановлення.
4. Відкрийте Termux і дочекайтеся, поки він підготується.

Якщо Termux уже встановлений, не видаляйте його: там можуть бути ваші файли. Залиште кілька гігабайтів вільного місця й за можливості користуйтеся Wi-Fi.

## 2. Підготуйте Termux

**Де: у Termux.** Вставляйте по одному блоку.

Оновіть інструменти:

```sh
pkg update
pkg upgrade
```

Надайте доступ до файлів телефона:

```sh
termux-setup-storage
```

У запиті Android натисніть **Дозволити**. Перевірте доступ:

```sh
ls ~/storage/downloads
```

**Має з’явитися:** список ваших завантажень. Якщо папка порожня, список буде порожнім. `Permission denied` означає, що доступу немає — далі не переходьте.

## 3. Встановіть Ubuntu

Ubuntu потрібна, щоб програми для відео працювали всередині Termux. Вона не замінює Android і не потребує root-прав на телефоні.

**Де: у тому самому Termux.**

```sh
pkg install proot-distro
```

```sh
proot-distro list
```

Якщо Ubuntu вже встановлена, пропустіть наступний блок. Якщо ні:

```sh
proot-distro install ubuntu
```

Зачекайте завершення завантаження. Потім відкрийте Ubuntu:

```sh
proot-distro login ubuntu --bind /storage/emulated/0:/storage/emulated/0
```

**Ви залишаєтесь у застосунку Termux, але команди тепер виконує Ubuntu.** Перевірте:

```sh
cat /etc/os-release
```

**Має з’явитися:** назва Ubuntu. Усі наступні команди до кроку 7 вводьте тут.

## 4. Встановіть програми для відео та Codex

**Де: у Termux з відкритою Ubuntu.**

```sh
apt update
apt install nodejs npm git python3 ffmpeg ca-certificates
```

Коли встановлення завершиться:

```sh
npm install -g @openai/codex
```

Перевірте:

```sh
codex --version
```

**Має з’явитися:** `codex-cli` та номер версії. Якщо є помилка, не встановлюйте все заново — [попросіть допомоги](help.md).

## 5. Увійдіть у свій обліковий запис

**Де: у Termux з відкритою Ubuntu.**

```sh
codex login --device-auth
```

1. Відкрийте посилання, яке покаже Codex, у браузері цього самого телефона.
2. Увійдіть у свій ChatGPT і введіть показаний тимчасовий код.
3. Поверніться до Termux. Сам Termux під час входу не закривайте.

Перевірте вхід:

```sh
codex login status
```

**Має з’явитися:** повідомлення про виконаний вхід. Нікому не надсилайте код. Якщо вхід за кодом недоступний, дивіться [допомогу](help.md).

## 6. Завантажте проєкт

**Де: у Termux з відкритою Ubuntu.**

```sh
mkdir -p ~/projects
cd ~/projects
```

```sh
git clone https://github.com/before-we-build/agentic-evangelism.git
```

Якщо повідомляє, що папка `agentic-evangelism` уже існує, не видаляйте її. Просто продовжте:

```sh
cd ~/projects/agentic-evangelism
```

Встановіть скіл — готові інструкції для помічника:

```sh
python3 scripts/install_skill.py
```

**Має з’явитися:** `Встановлено / Установлено / Installed` і шлях до скіла. Якщо копія вже є, програма залишить її без змін; [допомога пояснює, що робити](help.md).

## 7. Відкрийте помічника й перевірте готовність

У тому самому вікні введіть:

```sh
codex
```

Прочитайте запит про довіру до папки й дозволи. Тепер перед вами **розмова з Codex**. Надішліть йому звичайний текст:

> Перевір, чи готовий мій телефон до створення відео: чи бачиш скіл suno-tiktok-video, завантажені файли та програми ffmpeg і ffprobe. Чи можеш ти саме в цій розмові створювати й зберігати картинки? Поки нічого не генеруй і не витрачай коштів. Поясни простими словами, що готове, а чого бракує.

**Готово, коли:** Codex бачить пісню в Завантаженнях, може запустити програми для відео й має доступ до генерації або ваших власних картинок. Саме встановлення скіла не відкриває генерацію зображень.

👉 Далі: **[створити відео](first-video.md)**. Наступного разу встановлення повторювати не потрібно.
