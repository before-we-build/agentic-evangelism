# Як почати без зайвих витрат

Українська · [Русский](../ru/costs.md) · [English](../en/costs.md)

**Не купуйте підписки лише для того, щоб спробувати.** Почніть із дозволеного запису пісні та власних фотографій. Suno для цього не потрібен. Можна попросити когось у церкві допомогти з першим відео.

## Якщо потрібна пісня із Suno

Перевірено 12 вересня 2026 року. Правила завантаження змінилися 3 вересня.

| Варіант | Ціна та головне обмеження |
| --- | --- |
| Free — спробувати | $0; до 7 пробних завантажень за весь час існування облікового запису, лише для особистого некомерційного використання. |
| Pro — найдешевший платний | Орієнтир $10 за місяць при помісячній оплаті; 20 завантажень пісень на місяць. |

Безкоштовні пробні завантаження не поновлюються щомісяця. Коли вони закінчаться, можна слухати пісні та ділитися посиланнями в Suno. [Правила завантаження](https://help.suno.com/en/articles/13614785).

На сторінці тарифів **$8/місяць означає річну оплату — $96 одразу**, до податків. Для першої спроби обирайте Monthly, якщо вирішили платити. Pro має 2500 кредитів на місяць: це запас для створення музики, окремий від кількості завантажень. Остаточну суму перевірте перед оплатою. [Тарифи](https://suno.com/pricing) · [Довідка про помісячну ціну](https://help.suno.com/en/articles/2425729).

## Чи можна публікувати

Відсутність заробітку сама по собі не означає, що церковний канал є «особистим використанням». Для такого каналу уточніть дозвіл у Suno або використайте інший дозволений запис.

Актуальна довідка Suno пов’язує комерційні права з офіційним завантаженням під час платної підписки. Старі довідки описують інші правила для пісень із Free; для старої пісні уточніть її статус у підтримки. [Права платного плану](https://help.suno.com/en/articles/9601665).

Підписка не дає дозволу на чужі слова чи музику. Для спільних реміксів у Suno діє окреме некомерційне обмеження навіть на платному плані. Не обходьте недоступне завантаження записом звуку з екрана. [Умови Suno](https://about.suno.com/terms).

## Якщо бюджет обмежений

- Використайте власну пісню та запис або отримайте дозвіл на пісню, запис і публікацію відео. Власний запис чужої пісні не замінює такого дозволу.
- Візьміть власні фотографії замість платної генерації картинок: [як створити відео](first-video.md).
- Почніть із доступного безкоштовного Codex у межах його лімітів: [вартість і обмеження](README.md). Безкоштовний проєкт не означає безлімітні ШІ-сервіси.
- Якщо потрібен Suno Pro, можна оплатити один місяць і скасувати поновлення до наступного списання. Права на дозволені комерційні завантаження зберігаються після скасування. [Підписка й права](https://about.suno.com/terms).

Не потрібно, щоб кожен у молодіжній групі купував підписки. Можна розподілити роботу: хтось пише текст, хтось фотографує, хтось збирає відео. Паролі залишаються у власників облікових записів.
