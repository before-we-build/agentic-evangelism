# Виберіть ваш пристрій

Українська · [Русский](../ru/setup.md) · [English](../en/setup.md)

Виберіть платформу, на якій ви хочете налаштувати та запускати скіл:

- **[Телефон на Android](phone-setup.md)** — Запуск на телефоні через Termux та PRoot Ubuntu. Комп'ютер не потрібен.
- **[Комп'ютер на Windows](setup-windows.md)** — Запуск на Windows через PowerShell або командний рядок.
- **[Комп'ютер Mac (macOS)](setup-macos.md)** — Запуск на macOS через Terminal та Homebrew.
- **[Комп'ютер або сервер на Linux](setup-linux.md)** — Запуск на Ubuntu, Debian, Fedora, Arch або сервері.

Після завершення налаштування переходьте до [створення першого відео](first-video.md).
