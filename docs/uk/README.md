# Почніть тут

Українська · [Русский](../ru/README.md) · [English](../en/README.md)

Цей проєкт допомагає готувати християнські пісні, ілюстрації та відео за допомогою ШІ. «Агентний» означає, що помічник може виконати кілька кроків: знайти ваш аудіофайл, прочитати текст пісні, скласти план сцен, підготувати картинки й зібрати відео. Ви обираєте, що хочете сказати, перевіряєте результат і вирішуєте, чим поділитися.

Перший робочий приклад — повна пісня, перетворена на вертикальне відео для TikTok. Картинки змінюються під музику. Це слайд-шоу зі статичних зображень, а не рухома ШІ-анімація. Незалежні картинки замовляються паралельно, якщо сервіс це дозволяє.

## Що знадобиться

- Телефон з Android, інтернет і місце для інструментів Linux, картинок та відео. Для початку практично залишити кілька вільних гігабайтів, але це не гарантована вимога до обсягу. Під час збирання відео стежте за зарядом телефона.
- Обліковий запис із доступом до Codex. Для створення картинок у сесії має бути окремо доступний інструмент генерації зображень; встановлення цього репозиторію його не відкриває. Перш ніж за щось платити, перевірте доступ і вартість у своєму обліковому записі.
- Завантажена пісня, яку ви маєте право використовувати, та її текст, якщо його немає всередині аудіофайлу.

Для основного способу вам не потрібні комп’ютер, обліковий запис GitHub лише для завантаження репозиторію, LabelGrid, ADB чи знання програмування. Під час налаштування ви скопіюєте кілька команд. Посібник пояснює, куди їх вставити та як зрозуміти, що кожен крок спрацював.

Цей спосіб призначений для **Android із Termux та Ubuntu**. Аналогічне локальне налаштування на iPhone ми не перевіряли. На iPhone можна готувати текст і картинки в браузері та користуватися відеоредактором на телефоні, але це окремий ручний процес.

## Оберіть наступний крок

1. Уперше з цим стикаєтеся? Пройдіть [налаштування телефона](phone-setup.md).
2. Codex уже працює на вашому телефоні? Перейдіть до кроку завантаження репозиторію в тому посібнику, а потім [створіть перше відео](first-video.md).
3. Щось не спрацювало? Знайдіть повідомлення в розділі [усунення несправностей](troubleshooting.md).
4. Допомагаєте іншим або оновлюєте проєкт? Прочитайте [про підтримку та перевірені результати](maintenance.md).

## Кілька слів із посібника

| Слово | Що воно означає тут |
| --- | --- |
| Термінал | Екран застосунку, де ви вводите або вставляєте команди. |
| Termux | Застосунок Android, який дає такий екран і базові інструменти. |
| Ubuntu / Linux | Робоче середовище всередині Termux, у якому запускаються інструменти цього посібника. Воно не замінює Android. |
| Codex | ШІ-помічник, якому ви даєте завдання звичайною мовою. |
| Навичка, або скіл | Папка з інструкціями та допоміжними програмами, яка навчає помічника виконувати певну послідовність дій. |
| Репозиторій | Папка проєкту та її копія на GitHub. |
| Рендеринг | Перетворення картинок і звуку на готовий відеофайл. |

## Як ми використовуємо ШІ для євангелізації

Починайте з думки, за яку ви готові відповідати. Звіряйте біблійні цитати з перекладом, який хочете використати. Називайте тлумачення тлумаченнями; не видавайте вигадані вислови за Писання, свідчення чи слова від Бога. Якщо потрібна допомога зі змістом, попросіть довіреного члена церкви або пастора переглянути матеріал.

Ставтеся до людей по-людськи: чесна розмова, право припинити спілкування, без спаму, видавання себе за когось іншого чи тиску. Цей репозиторій готує матеріали; він не розсилає автоматичні повідомлення незнайомцям. Чесно описуйте участь ШІ та перед поширенням перевіряйте аудіо, картинки й зображення конкретних людей. Публікація — окреме рішення людини.

Ці інструкції незалежні від OpenAI, Suno, TikTok і Termux; вони не означають офіційного схвалення з боку цих сервісів. Досвід роботи на телефоні та його межі описані в розділі [про підтримку](maintenance.md).
