# Створити відео під пісню

Українська · [Русский](../ru/first-video.md) · [English](../en/first-video.md)

Телефон налаштовується [один раз](phone-setup.md). Після цього для кожної нової пісні повторюйте лише кроки нижче.

**Підписка Suno не обов’язкова.** Можна взяти дозволений запис пісні та власні фото. Якщо потрібен Suno: Free має обмеження, а найдешевший платний план Pro коштує орієнтовно $10 за місяць при помісячній оплаті. [Як почати без зайвих витрат і які обмеження Suno](costs.md).

## 1. Завантажте пісню

Збережіть аудіо із Suno або іншого джерела, яке можна використовувати. Дочекайтеся завершення завантаження.

Відкрийте **Файли → Завантаження**. Знайдіть пісню й запам’ятайте назву. Не видаляйте оригінал. Якщо маєте кілька версій, оберіть потрібну.

## 2. Відкрийте Codex

Якщо ви щойно завершили налаштування й розмова з Codex уже відкрита — переходьте до кроку 3.

<details>
<summary>Як знову відкрити Codex після перерви</summary>

Інакше відкрийте **Termux**. Якщо в ньому вже відкрита розмова з Codex, також переходьте до кроку 3.

Якщо бачите звичайний рядок для команд, перевірте:

```sh
cat /etc/os-release
```

Якщо у відповіді є **Ubuntu**, наступний блок пропустіть. Якщо файл не знайдено, відкрийте Ubuntu:

```sh
proot-distro login ubuntu --bind /storage/emulated/0:/storage/emulated/0
```

Відкрийте папку проєкту й помічника, по одному блоку:

```sh
cd ~/projects/agentic-evangelism
```

```sh
codex
```

**Має з’явитися:** поле, у якому можна написати прохання до помічника. Якщо бачите помилку, відкрийте [допомогу](help.md).

</details>

## 3. Попросіть зробити відео

Скопіюйте повідомлення нижче **в розмову з Codex**. Замість `Моя пісня.mp3` напишіть справжню назву свого файлу:

> Використай $suno-tiktok-video. У Завантаженнях є моя пісня «Моя пісня.mp3». Зроби відео на всю пісню з картинками за її змістом. Якщо бракує тексту або картинок, поясни, що мені зробити. Збережи відео в Завантаженнях. Не публікуй його.

Codex має показати файл і пояснити, які картинки підготує. Якщо просить текст пісні — надішліть його. Якщо просить обрати одну з кількох версій — назвіть потрібну.

Коли з’являється запит дозволу, прочитайте дію та назву файлу. Дозволяйте лише те, що потрібно для вашого відео. Якщо незрозуміло — попросіть пояснити.

Картинки будуть нерухомими, а переходи між ними — приблизно за змістом пісні, без точного збігу зі словами. Пісня звучатиме повністю.

<details>
<summary>Немає генерації? Використайте власні картинки</summary>

Збережіть потрібні картинки в **Завантаження**. У застосунку Файли можна затиснути файл → **Перейменувати** й дати прості назви: `scene-01.jpg`, `scene-02.jpg`. Залишайте справжнє закінчення файлу: `.png` не треба міняти на `.jpg`.

Надішліть Codex повідомлення зі справжніми назвами всіх обраних картинок:

> Для цієї пісні використай мої картинки із Завантажень: спочатку scene-01.jpg, потім scene-02.jpg. Переглянь їх. Якщо для змісту пісні бракує інших сцен — скажи мені. Нові картинки не генеруй. Збережи відео на всю пісню в Завантаженнях, нічого не публікуй.

Нові ШІ-ілюстрації потребують доступу до сервісу генерації. Якщо Codex його не має, він може підготувати описи для іншого сервісу, яким ви користуєтеся. Окремий платний спосіб не вмикається без вашої згоди.

</details>

## 4. Перегляньте результат

Відкрийте **Файли → Завантаження → новий MP4**. Назву готового файлу повідомить Codex.

Перегляньте відео й прослухайте всю пісню. Перевірте слова, біблійні цитати, обличчя, руки та зміст картинок. ШІ може помилятися; не видавайте вигадану сцену за справжню подію чи свідчення.

Якщо щось не подобається, напишіть, наприклад:

> Зміни третю картинку: нехай вона показує допомогу ближньому. Решту й повну пісню збережи. Зроби нову версію файлу.

Стару версію збережіть, доки не переглянете нову.

## 5. Поділіться, коли будете готові

Відкрийте YouTube, TikTok чи Instagram, оберіть завантаження відео та свій MP4. Перевірте, чи сервіс приймає його тривалість, і перегляньте попередній перегляд перед публікацією. Чесно вкажіть участь ШІ.

Якщо відео є у Файлах, але його немає у виборі — закрийте й знову відкрийте вікно вибору, пошукайте в **Відео / Завантаження**. [Ще підказки](help.md).

Публікуєте ви. Codex у цьому завданні лише готує файл. Наступну пісню можна попросити зробити в тій самій розмові.
