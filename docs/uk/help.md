# Щось не виходить

Українська · [Русский](../ru/help.md) · [English](../en/help.md)

Не починайте встановлення заново й не видаляйте файли. Спершу знайдіть свою ситуацію нижче.

| Що сталося | Що зробити |
| --- | --- |
| Текст довго рухається на екрані | Можливо, програма ще встановлюється. Дочекайтеся повернення рядка для введення. |
| Зупинилося на `[Y/n]` | Це запит. Введіть `y` і Enter, якщо погоджуєтеся продовжити саме це встановлення. |
| `Permission denied` біля Завантажень | У налаштуваннях Android перевірте дозвіл Termux на доступ до файлів. Дивіться крок 2 налаштування. |
| `command not found` | Можливо, команду вставлено не туди. `pkg` працює у Termux, `apt` — всередині Ubuntu. Не встановлюйте все заново. |
| Вхід за кодом не працює | Код міг закінчитися. Спробуйте свіжий код або попросіть допомогти зі звичайним входом `codex login`. Іноді вхід за кодом треба дозволити в налаштуваннях ChatGPT. |
| Codex не бачить скіл | У розмові введіть `/skills`. Якщо `suno-tiktok-video` немає, перезапустіть Codex. Якщо не допомогло — покажіть помічнику крок 6 налаштування. |
| Написано, що скіл уже існує | Наявну копію не змінено. Якщо вона є в `/skills`, можна продовжити. Якщо ні — попросіть допомогти перевірити її розташування. |
| Codex не може створити картинки | Скористайтеся власними картинками: інструкція є в кроці 3 створення відео. Встановлення скіла саме по собі не відкриває генерацію. |
| Відео не зібралося або файл уже є | Збережіть оригінал. Попросіть Codex пояснити помилку та використати нову назву для результату. |
| У Файлах відео є, а в TikTok немає | Відкрийте його у Файлах, закрийте й знову відкрийте вибір у TikTok. Шукайте точну назву у Відео або Завантаженнях. |

## Як попросити допомоги

Якщо Codex працює, напишіть йому. Якщо ще не запускається — покажіть цей текст людині, яка допомагає з налаштуванням:

> Я налаштовую телефон за інструкцією agentic-evangelism. Зупинився на кроці __. Зараз відкрито __. На екрані написано: __. Поясни одну наступну дію простими словами. Не видаляй мої файли й не вимикай усі захисти.

Заповніть пропуски. Можна показати знімок екрана з помилкою, але спочатку приховайте паролі, коди входу й особисті дані. Не надсилайте всю історію розмов або файли налаштувань облікового запису.

**Для людини, яка допомагає:** [технічна довідка](troubleshooting.md). Там є перевірка середовища, встановленого скіла, помилок `bwrap` і необов’язкове підключення через ADB. ADB не потрібен для звичайного створення відео.
