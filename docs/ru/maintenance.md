# Поддержка проекта и подтверждённый опыт

[Українська](../uk/maintenance.md) · Русский · [English](../en/maintenance.md)

## Что находится в репозитории

Руководства для людей находятся в `docs/en`, `docs/ru` и `docs/uk`. Корневой README — начальная страница на трёх языках. У каждого руководства одинаковое имя файла во всех трёх папках. Скилл находится в `skills/suno-tiktok-video`; `SKILL.md` — английский файл, который читает помощник для выполнения скилла, рядом лежат русская и украинская копии для чтения. Копии описывают один процесс работы, а не три разных скилла. Справочные документы тоже переведены. Идентификаторы Python и команды оболочки одинаковы во всех языках.

`scripts/install_skill.py` устанавливает выбранный скилл из репозитория (`suno-tiktok-video` по умолчанию или `--skill dual-image-pipeline`). Он не устанавливает сторонние инструменты, не меняет разрешения, не редактирует настройки учётной записи и ничего не публикует. При существующей папке назначения он отказывается продолжать без `--update`. Обновление сохраняет полную резервную копию рядом и оставляет исключительно локальные файлы. Указывайте `--destination PATH`, только если знаете, откуда ваша установка Codex читает скиллы.

## Как внести изменение и сохранить согласованность языков

1. Опишите изменение и то, что оно меняет для пользователя.
2. Вместе обновите английскую, русскую и украинскую версии руководства, включая команды и оговорки. Так же обновляйте переводы скилла и справочных документов.
3. Запустите локальные проверки из корня репозитория:

```sh
python3 scripts/check_docs.py
python3 -m unittest discover -s tests -v
```

4. При изменении вспомогательной программы для медиа дополнительно выполните короткую пробную сборку со сгенерированным звуком и сценами через FFmpeg и осмотрите результат. Не включайте тестовые медиафайлы в отслеживаемые файлы проекта.
5. Перед публикацией просмотрите `git diff` и `git status --short`. Включайте в коммит только предназначенные для проекта файлы. Не добавляйте домашнюю папку Codex, выгрузки сеансов, файлы учётной записи или резервные копии телефона.

Автоматическая проверка документации проверяет наличие языковых версий и локальные ссылки; она не может подтвердить качество перевода, богословскую корректность или доступность сервисов. Тесты проверяют установщик и отдельные свойства вспомогательных программ без внешних учётных записей и расходов на генерацию изображений.

## Как помочь или обновить свою копию

Для предложения откройте issue на GitHub, указав шаг руководства, язык, при необходимости модель телефона/версию Android и короткую ошибку без личных данных. Никогда не прикладывайте файлы входа или полный частный сеанс. Небольшое предложенное исправление полезно, даже если вы не умеете программировать.

Чтобы обновить локальную копию без собственных изменений, выйдите из Codex, перейдите в папку репозитория внутри Ubuntu и выполните:

```sh
git status --short
```

Если команда ничего не вывела, локальных правок в списке нет. Если она показывает правки, которые вы хотите сохранить, попросите помочь сохранить их, прежде чем продолжать. Если локальная копия не изменена, выполните:

```sh
git pull --ff-only
```

Обновление репозитория не обновляет установленные скиллы. Сравнив локальные изменения, выполните приведённые команды в папке проекта, на Android в той же оболочке Termux/PRoot, если Codex действительно загружает `~/.codex/skills`:

```sh
python3 scripts/install_skill.py --destination ~/.codex/skills --skill dual-image-pipeline --update
python3 scripts/install_skill.py --destination ~/.codex/skills --skill suno-tiktok-video --update
```

Для другой установки подставьте проверенный каталог скиллов. Ожидаются путь установленного скилла и, для существующей копии, путь резервной копии. Проверьте результат и перезапустите Codex для загрузки обновлённых инструкций. Сохраняйте резервную копию до проверки обновления. Автоматические публикации, учётные записи дистрибуции и массовое обращение к людям не входят в этот начальный процесс работы.
