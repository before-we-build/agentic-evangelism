# Создать видео под песню

[Українська](../uk/first-video.md) · Русский · [English](../en/first-video.md)

Телефон настраивается [один раз](phone-setup.md). После этого для каждой новой песни повторяйте только шаги ниже.

**Подписка Suno не обязательна.** Можно взять разрешённую запись песни и свои фото. Если нужен Suno: Free имеет ограничения, а самый дешёвый платный план Pro стоит ориентировочно $10 за месяц при помесячной оплате. [Как начать без лишних расходов и какие ограничения у Suno](costs.md).

## 1. Скачайте песню

Сохраните аудио из Suno или другого источника, который можно использовать. Дождитесь завершения скачивания.

Откройте **Файлы → Загрузки**. Найдите песню и запомните название. Не удаляйте оригинал. Если у вас несколько версий, выберите нужную.

## 2. Откройте Codex

Если вы только что закончили настройку и разговор с Codex уже открыт — переходите к шагу 3.

<details>
<summary>Как снова открыть Codex после перерыва</summary>

Иначе откройте **Termux**. Если в нём уже открыт разговор с Codex, тоже переходите к шагу 3.

Если видите обычную строку для команд, проверьте:

```sh
cat /etc/os-release
```

Если в ответе есть **Ubuntu**, пропустите следующий блок. Если файл не найден, откройте Ubuntu:

```sh
proot-distro login ubuntu --bind /storage/emulated/0:/storage/emulated/0
```

Откройте папку проекта и помощника, по одному блоку:

```sh
cd ~/projects/agentic-evangelism
```

```sh
codex
```

**Должно появиться:** поле, в котором можно написать просьбу помощнику. Если видите ошибку, откройте [помощь](help.md).

</details>

## 3. Попросите сделать видео

Скопируйте сообщение ниже **в разговор с Codex**. Вместо `Моя песня.mp3` напишите настоящее имя своего файла:

> Используй $suno-tiktok-video. В «Загрузках» есть моя песня «Моя песня.mp3». Сделай видео на всю песню с картинками по её смыслу. Если не хватает текста или картинок, объясни, что мне сделать. Сохрани видео в «Загрузках». Не публикуй его.

Codex должен показать файл и объяснить, какие картинки подготовит. Если просит текст песни — отправьте его. Если просит выбрать одну из нескольких версий — назовите нужную.

Когда появляется запрос разрешения, прочитайте действие и имя файла. Разрешайте только то, что нужно для вашего видео. Если непонятно — попросите объяснить.

Картинки будут неподвижными, а сменяться они будут примерно по смыслу песни, без точного совпадения со словами. Переходы между картинками по умолчанию делаются плавными (растворение / наплыв). Если нужны резкие стыки без наплыва, можно попросить сделать склейки без переходов (`--transition none`). Песня будет звучать полностью.

**Совет по стилю и персонажам:** Если у вас сюжетная песня или вы хотите конкретный художественный стиль, добавьте это в запрос, например:
> Сделай иллюстрации в едином стиле реалистичной цифровой живописи. Главный герой — путник около 40 лет в тёмно-синей куртке и охристом шарфе; сохрани его внешность и одежду во всех сценах с его участием.

<details>
<summary>Нет генерации? Используйте свои картинки</summary>

Сохраните нужные картинки в **Загрузки**. В приложении «Файлы» можно нажать и удерживать файл → **Переименовать** и дать простые имена: `scene-01.jpg`, `scene-02.jpg`. Оставляйте настоящее окончание файла: `.png` не нужно менять на `.jpg`.

Отправьте Codex сообщение с настоящими именами всех выбранных картинок:

> Для этой песни используй мои картинки из «Загрузок»: сначала scene-01.jpg, потом scene-02.jpg. Просмотри их. Если для смысла песни не хватает других сцен — скажи мне. Новые картинки не генерируй. Сохрани видео на всю песню в «Загрузках», ничего не публикуй.

Новые ИИ-иллюстрации требуют доступа к сервису генерации. Если у Codex его нет, он может подготовить описания для другого сервиса, которым вы пользуетесь. Отдельный платный способ не включается без вашего согласия.

</details>

## 4. Посмотрите результат

Откройте **Файлы → Загрузки → новый MP4**. Имя готового файла сообщит Codex.

Посмотрите видео и прослушайте всю песню. Проверьте слова, библейские цитаты, лица, руки и смысл картинок. ИИ может ошибаться; не выдавайте выдуманную сцену за настоящее событие или свидетельство.

Если что-то не нравится, напишите, например:

> Измени третью картинку: пусть она показывает помощь ближнему. Всё остальное и полную песню сохрани. Сделай новую версию файла.

Сохраните старую версию, пока не посмотрите новую.

## 5. Поделитесь, когда будете готовы

Откройте YouTube, TikTok или Instagram, выберите загрузку видео и свой MP4. Проверьте, принимает ли сервис его длительность, и посмотрите предварительный просмотр перед публикацией. Честно укажите участие ИИ.

Если видео есть в «Файлах», но его нет в выборе — закройте и снова откройте окно выбора, поищите в **Видео / Загрузки**. [Ещё подсказки](help.md).

Публикуете вы. Codex в этом задании только готовит файл. Следующую песню можно попросить сделать в том же разговоре.
