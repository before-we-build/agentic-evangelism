# Как начать без лишних расходов

[Українська](../uk/costs.md) · Русский · [English](../en/costs.md)

**Не покупайте подписки только ради первой пробы.** Начните с разрешённой записи песни и своих фотографий. Suno для этого не нужен. Можно попросить кого-нибудь в церкви помочь с первым видео.

## Если нужна песня из Suno

Проверено 12 сентября 2026 года. Правила скачивания изменились 3 сентября.

| Вариант | Цена и главное ограничение |
| --- | --- |
| Free — попробовать | $0; до 7 пробных скачиваний за всё время существования аккаунта, только для личного некоммерческого использования. |
| Pro — самый дешёвый платный | Ориентир $10 за месяц при помесячной оплате; 20 скачиваний песен в месяц. |

Бесплатные пробные скачивания не возобновляются каждый месяц. Когда они закончатся, можно слушать песни и делиться ссылками в Suno. [Правила скачивания](https://help.suno.com/en/articles/13614785).

На странице тарифов **$8/месяц означает годовую оплату — $96 сразу**, до налогов. Для первой пробы выбирайте Monthly, если решили платить. Pro включает 2500 кредитов в месяц: это запас для создания музыки, отдельный от числа скачиваний. Окончательную сумму проверьте перед оплатой. [Тарифы](https://suno.com/pricing) · [Справка о помесячной цене](https://help.suno.com/en/articles/2425729).

## Можно ли публиковать

Отсутствие заработка само по себе не означает, что церковный канал является «личным использованием». Для такого канала уточните разрешение у Suno или используйте другую разрешённую запись.

Актуальная справка Suno связывает коммерческие права с официальным скачиванием во время платной подписки. Старые справки описывают другие правила для песен из Free; для старой песни уточните её статус у поддержки. [Права платного плана](https://help.suno.com/en/articles/9601665).

Подписка не даёт разрешения на чужие слова или музыку. Для совместных ремиксов в Suno действует отдельное некоммерческое ограничение даже на платном плане. Не обходите недоступное скачивание записью звука с экрана. [Условия Suno](https://about.suno.com/terms).

## Если бюджет ограничен

- Используйте собственную песню и запись или получите разрешение на песню, запись и публикацию видео. Своя запись чужой песни не заменяет такого разрешения.
- Возьмите свои фотографии вместо платной генерации картинок: [как создать видео](first-video.md).
- Начните с доступного бесплатного Codex в пределах его лимитов: [стоимость и ограничения](README.md). Бесплатный проект не означает безлимитные ИИ-сервисы.
- Если нужен Suno Pro, можно оплатить один месяц и отменить продление до следующего списания. Права на разрешённые коммерческие скачивания сохраняются после отмены. [Подписка и права](https://about.suno.com/terms).

Не нужно, чтобы каждый в молодёжной группе покупал подписки. Можно распределить работу: кто-то пишет текст, кто-то фотографирует, кто-то собирает видео. Пароли остаются у владельцев аккаунтов.
