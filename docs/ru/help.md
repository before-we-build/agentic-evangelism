# Что-то не получается

[Українська](../uk/help.md) · Русский · [English](../en/help.md)

Не начинайте установку заново и не удаляйте файлы. Сначала найдите свою ситуацию ниже.

| Что случилось | Что сделать |
| --- | --- |
| Текст долго движется на экране | Возможно, программа ещё устанавливается. Дождитесь возвращения строки для ввода. |
| Остановилось на `[Y/n]` | Это вопрос. Введите `y` и Enter, если согласны продолжить именно эту установку. |
| `Permission denied` возле загрузок | В настройках Android проверьте разрешение Termux на доступ к файлам. См. шаг 2 настройки. |
| `command not found` | Возможно, команда вставлена не туда. `pkg` работает в Termux, `apt` — внутри Ubuntu. Не устанавливайте всё заново. |
| Вход по коду не работает | Срок действия кода мог истечь. Попробуйте свежий код или попросите помочь с обычным входом `codex login`. Иногда вход по коду нужно разрешить в настройках ChatGPT. |
| Codex не видит скилл | В разговоре введите `/skills`. Если `suno-tiktok-video` нет, перезапустите Codex. Если не помогло — покажите помощнику шаг 6 настройки. |
| Написано, что скилл уже существует | Существующая копия не изменена. Если она есть в `/skills`, можно продолжить. Если нет — попросите помочь проверить её расположение. |
| Codex не может создавать картинки | Используйте свои картинки: инструкция есть в шаге 3 создания видео. Установка скилла сама по себе не открывает генерацию. |
| Видео не собралось или файл уже есть | Сохраните оригинал. Попросите Codex объяснить ошибку и использовать новое имя для результата. |
| В «Файлах» видео есть, а в TikTok нет | Откройте его в «Файлах», закройте и снова откройте выбор файлов в TikTok. Ищите точное имя в «Видео» или «Загрузках». |

## Как попросить помощи

Если Codex работает, напишите ему. Если ещё не запускается — покажите этот текст человеку, который помогает с настройкой:

> Я настраиваю телефон по инструкции agentic-evangelism. Остановился на шаге __. Сейчас открыто __. На экране написано: __. Объясни одно следующее действие простыми словами. Не удаляй мои файлы и не отключай все защиты.

Заполните пропуски. Можно показать снимок экрана с ошибкой, но сначала скройте пароли, коды входа и личные данные. Не отправляйте всю историю разговоров или файлы настроек учётной записи.

**Для человека, который помогает:** [техническая справка](troubleshooting.md). Там есть проверка среды, установленного скилла, ошибок `bwrap` и необязательное подключение через ADB. Для обычного создания видео ADB не нужен.
