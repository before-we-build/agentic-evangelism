# Выберите устройство

[Українська](../uk/setup.md) · Русский · [English](../en/setup.md)

Выберите платформу, на которой вы хотите настроить и запускать скилл:

- **[Телефон на Android](phone-setup.md)** — Запуск на телефоне через Termux и PRoot Ubuntu. Компьютер не требуется.
- **[Компьютер на Windows](setup-windows.md)** — Запуск на Windows через PowerShell или командную строку.
- **[Компьютер Mac (macOS)](setup-macos.md)** — Запуск на macOS через Terminal и Homebrew.
- **[Компьютер или сервер на Linux](setup-linux.md)** — Запуск на Ubuntu, Debian, Fedora, Arch или сервере.

После завершения настройки переходите к [созданию первого видео](first-video.md).
