# Настроить телефон один раз

[Українська](../uk/phone-setup.md) · Русский · [English](../en/phone-setup.md)

Вам понадобятся телефон на Android и интернет. Компьютер не требуется. Если вы используете компьютер (Windows, Mac или Linux), смотрите общее [руководство по настройке](setup.md). Если Codex уже работает и видит скилл `suno-tiktok-video`, сразу переходите к [созданию видео](first-video.md).

**Как выполнять шаги:** скопируйте текст из серого блока, нажмите и удерживайте экран в нужном приложении → **Вставить** → **Enter**. Дождитесь завершения. Только потом переходите дальше.

Если видите вопрос `Do you want to continue? [Y/n]`, введите `y` и нажмите Enter, чтобы продолжить установку. Если появилась ошибка или непонятный вопрос о замене файлов — остановитесь и откройте [помощь](help.md).

**Подписка Suno не обязательна.** Можно взять разрешённую запись песни и свои фото. Если нужен Suno: Free имеет ограничения, а самый дешёвый платный план Pro стоит ориентировочно $10 за месяц при помесячной оплате. [Как начать без лишних расходов и какие ограничения у Suno](costs.md).

## 1. Установите Termux

Termux — приложение, в которое вы будете вставлять команды ниже.

1. Откройте [страницу скачивания Termux](https://f-droid.org/en/packages/com.termux/).
2. Найдите **Download APK**, скачайте и откройте файл. Устанавливать сам F-Droid необязательно.
3. Если Android попросит разрешение установить приложение из браузера — разрешите эту установку.
4. Откройте Termux и дождитесь, пока он подготовится.

Если Termux уже установлен, не удаляйте его: там могут быть ваши файлы. Оставьте несколько гигабайт свободного места и по возможности пользуйтесь Wi-Fi.

## 2. Подготовьте Termux

**Где: в Termux.** Вставляйте по одному блоку.

Обновите инструменты:

```sh
pkg update
pkg upgrade
```

Дайте доступ к файлам телефона:

```sh
termux-setup-storage
```

В запросе Android нажмите **Разрешить**. Проверьте доступ:

```sh
ls ~/storage/downloads
```

**Должно появиться:** список ваших загрузок. Если папка пустая, список будет пустым. `Permission denied` означает, что доступа нет — дальше не переходите.

## 3. Установите Ubuntu

Ubuntu нужна, чтобы программы для видео работали внутри Termux. Она не заменяет Android и не требует root-прав на телефоне.

**Где: в том же Termux.**

```sh
pkg install proot-distro
```

```sh
proot-distro list
```

Если Ubuntu уже установлена, пропустите следующий блок. Если нет:

```sh
proot-distro install ubuntu
```

Дождитесь завершения скачивания. Затем откройте Ubuntu:

```sh
proot-distro login ubuntu --bind /storage/emulated/0:/storage/emulated/0
```

**Вы остаётесь в приложении Termux, но команды теперь выполняет Ubuntu.** Проверьте:

```sh
cat /etc/os-release
```

**Должно появиться:** название Ubuntu. Все следующие команды до шага 7 вводите здесь.

## 4. Установите программы для видео и Codex

**Где: в Termux с открытой Ubuntu.**

```sh
apt update
apt install nodejs npm git python3 ffmpeg ca-certificates
```

Когда установка закончится:

```sh
npm install -g @openai/codex
```

Проверьте:

```sh
codex --version
```

**Должно появиться:** `codex-cli` и номер версии. Если есть ошибка, не устанавливайте всё заново — [попросите помощи](help.md).

Если позже Codex покажет `bwrap: Can't get type of source /tmp/codex-bwrap-synthetic-mount-targets-...`, откройте [проверенный обход для PRoot](troubleshooting.md#агент-сообщает-об-ошибке-песочницы-или-bwrap). Это ошибка запуска песочницы, а не причина переустанавливать программы для видео.

## 5. Войдите в свою учётную запись

**Где: в Termux с открытой Ubuntu.**

```sh
codex login --device-auth
```

1. Откройте ссылку, которую покажет Codex, в браузере этого же телефона.
2. Войдите в свой ChatGPT и введите показанный временный код.
3. Вернитесь в Termux. Сам Termux во время входа не закрывайте.

Проверьте вход:

```sh
codex login status
```

**Должно появиться:** сообщение об успешном входе. Никому не отправляйте код. Если вход по коду недоступен, смотрите [помощь](help.md).

## 6. Скачайте проект

**Где: в Termux с открытой Ubuntu.**

```sh
mkdir -p ~/projects
cd ~/projects
```

```sh
git clone https://github.com/before-we-build/agentic-evangelism.git
```

Если написано, что папка `agentic-evangelism` уже существует, не удаляйте её. Просто продолжите:

```sh
cd ~/projects/agentic-evangelism
```

Установите скилл — готовые инструкции для помощника:

```sh
python3 scripts/install_skill.py
```

**Должно появиться:** `Встановлено / Установлено / Installed` и путь к скиллу. Если копия уже есть, программа оставит её без изменений; [помощь объясняет, что делать](help.md).

## 7. Откройте помощника и проверьте готовность

В том же окне введите:

```sh
codex
```

Прочитайте запрос о доверии к папке и разрешениях. Теперь перед вами **разговор с Codex**. Отправьте ему обычный текст:

> Проверь, готов ли мой телефон к созданию видео: видишь ли ты скилл suno-tiktok-video, скачанные файлы и программы ffmpeg и ffprobe. Можешь ли ты именно в этом разговоре создавать и сохранять картинки? Пока ничего не генерируй и не трать деньги. Объясни простыми словами, что готово, а чего не хватает.

**Готово, когда:** Codex видит песню в «Загрузках», может запустить программы для видео и имеет доступ к генерации или вашим собственным картинкам. Сама установка скилла не открывает генерацию изображений.

👉 Дальше: **[создать видео](first-video.md)**. В следующий раз повторять установку не нужно.
