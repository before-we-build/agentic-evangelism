# Настройте телефон Android

[Українська](../uk/phone-setup.md) · Русский · [English](../en/phone-setup.md)

Всё можно сделать на одном телефоне. Держите эту страницу открытой в браузере и переключайтесь в Termux, когда об этом сказано. Если телефон поддерживает разделение экрана, так будет удобнее.

Руководство сочетает опыт работающей настройки телефона и шаги установки, восстановленные по актуальной документации. Сохранённые сеансы начинаются уже после первоначальной установки, поэтому чистая установка по этому руководству **не проверена** от начала до конца. См. [что было проверено](maintenance.md). Android/PRoot — путь, используемый сообществом, а не обещание официальной поддержки Codex.

## Перед началом

По возможности используйте Wi-Fi: установка Linux и инструментов требует скачивания значительного объёма данных. Освободите несколько гигабайт и дайте телефону время закончить. Не удаляйте уже установленный Termux ради начала с нуля: в его внутренних файлах могут храниться ваша работа и данные входа.

Прочитайте объяснение, скопируйте только содержимое блока с командами, вставьте в указанный экран и нажмите Enter. Дождитесь завершения команды и возвращения приглашения к вводу. Если команда сообщила об ошибке, остановитесь и откройте [решение проблем](troubleshooting.md); не вставляйте оставшиеся шаги поверх ошибки. Не вводите служебные `$` или `#` со скриншота чужого терминала.

## 1. Установите и откройте Termux

На телефоне откройте [страницу Termux в F-Droid](https://f-droid.org/en/packages/com.termux/), скачайте APK и откройте скачанный файл. Android может попросить разрешить установку из этого браузера. Разрешите её только для этой запланированной установки. Откройте Termux и дождитесь завершения первой настройки. Для дополнений Termux используйте тот же источник скачивания. [Инструкции установки Termux](https://github.com/termux/termux-app#installation).

**В Termux** обновите список инструментов и установленные пакеты:

```sh
pkg update
pkg upgrade
```

Прежде чем соглашаться, прочитайте запросы подтверждения. Вопрос вроде `Do you want to continue? [Y/n]` ждёт вашего ответа: введите `y` и нажмите Enter, чтобы продолжить запланированную установку. Если вопрос касается незнакомых настроек или замены файлов, попросите помощи, прежде чем выбирать. Бегущие сообщения о пакетах — это нормально. Признак успеха: команда закончилась, и снова можно вводить текст.

## 2. Дайте Termux доступ к загрузкам

**В Termux** выполните:

```sh
termux-setup-storage
```

Разрешите доступ к файлам в запросе Android, затем проверьте:

```sh
ls ~/storage/downloads
```

Признак успеха: вы видите имена файлов из папки загрузок телефона или пустой список, если она пуста. Сообщение `Permission denied` означает, что доступа нет. Выполняйте этот шаг в Termux, а не внутри Ubuntu. Если существующая установка уже показывает файлы, повторять настройку доступа не нужно.

## 3. Установите Ubuntu внутри Termux

**В Termux** установите программу управления средами:

```sh
pkg install proot-distro
```

Проверьте, нет ли уже установленной среды:

```sh
proot-distro list
```

Если Ubuntu уже установлена, используйте её; не сбрасывайте её состояние. Иначе установите:

```sh
proot-distro install ubuntu
```

Это может занять время. Затем войдите в Ubuntu, явно подключив общее хранилище телефона:

```sh
proot-distro login ubuntu --bind /storage/emulated/0:/storage/emulated/0
```

Признак успеха: приглашение к вводу изменится. Слово `root` здесь означает пользователя среды Linux; получать root-права в Android для этой настройки не требуется. Следующие команды Ubuntu вводятся на этом новом экране. Проверьте:

```sh
cat /etc/os-release
ls /storage/emulated/0/Download
```

Вы должны увидеть сведения об Ubuntu и имена скачанных файлов. [Инструкции PRoot-Distro](https://github.com/termux/proot-distro#quick-start). Версия установленного дистрибутива может отличаться от зафиксированной Ubuntu 26.04; не заменяйте работающую среду только ради совпадения версии.

## 4. Установите рабочие инструменты

**Внутри Ubuntu** выполните:

```sh
apt update
apt install nodejs npm git python3 ffmpeg ca-certificates
```

Эти пакеты позволяют запускать помощника, скачивать проект, выполнять вспомогательные программы и кодировать видео. Проверьте каждый инструмент:

```sh
node --version
npm --version
python3 --version
ffmpeg -version
ffprobe -version
```

Признак успеха: появляются сведения о версиях. В зафиксированной настройке использовался Node 22.22.1. Если при установке Codex ниже появится ошибка о неподдерживаемой версии Node, сохраните сообщение и попросите помочь обновить Node в Ubuntu; обновление Node в Termux изменит другую среду.

## 5. Установите Codex и войдите в учётную запись

**Внутри Ubuntu** установите официальный пакет npm, используемый в этом процессе:

```sh
npm install -g @openai/codex
codex --version
```

Признак успеха: Codex выводит версию. Зафиксирована версия 0.153.2; команда может установить более новую. [Codex CLI](https://developers.openai.com/codex/cli/).

Начните вход:

```sh
codex login --device-auth
```

Откройте показанную ссылку в браузере **на этом же телефоне**, войдите в учётную запись и введите временный код. Возможно, в настройках безопасности учётной записи потребуется разрешить вход по коду устройства. Вернитесь в Termux и проверьте:

```sh
codex login status
```

Вход по коду устройства зависит от настроек учётной записи. Если он недоступен, попробуйте `codex login` и откройте показанную ссылку на телефоне. Никому не отправляйте код или файл `auth.json`. Вход через ChatGPT и оплата API — разные способы доступа; в этом руководстве используется вход через ChatGPT. [Официальное руководство по входу](https://developers.openai.com/codex/auth/).

## 6. Скачайте проект и установите его скилл

**Внутри Ubuntu** разместите проект во внутреннем хранилище Linux. Готовые видео сохраняйте в папку загрузок Android.

```sh
mkdir -p ~/projects
cd ~/projects
git clone https://github.com/before-we-build/agentic-evangelism.git
cd agentic-evangelism
```

Если папка `agentic-evangelism` уже существует, войдите в неё командой `cd ~/projects/agentic-evangelism`; не удаляйте её и не клонируйте проект поверх неё.

Следующая команда копирует скилл в пользовательскую папку скиллов Codex и отказывается перезаписывать существующую копию:

```sh
python3 scripts/install_skill.py
```

Признак успеха: появляется путь установки, заканчивающийся на `suno-tiktok-video`. Копируются инструкции работы, а не сервис генерации изображений. Современный Codex читает пользовательские скиллы из `~/.agents/skills`; некоторые старые установки используют `~/.codex/skills`. Если скилл не виден, см. [решение проблем](troubleshooting.md). [Поиск локальных скиллов](https://developers.openai.com/codex/skills/).

## 7. Запустите помощника

**Внутри Ubuntu**, из папки проекта:

```sh
codex
```

Прочитайте запросы доверия и разрешений; подтвердите доверие к проекту, только если намерены разрешить работу с этими файлами. Внутри **Codex** введите `/skills` и найдите `suno-tiktok-video`. Затем отправьте обычное сообщение:

> Проверь, доступны ли скилл suno-tiktok-video, ffmpeg, ffprobe и папка загрузок Android. Также проверь, может ли этот сеанс действительно генерировать и сохранять картинки. Пока ничего не генерируй и не трать деньги. Объясни простыми словами, чего не хватает.

Если генерация картинок недоступна, попросите описания для сцен, создайте картинки в знакомом вам инструменте изображений, сохраните их в загрузки, затем явно попросите Codex использовать эти файлы. См. [первое видео](first-video.md). В новой установке Codex набор инструментов может отличаться от зафиксированного сеанса.

Всё готово, когда помощник может читать загрузки, запускать кодировщик видео и у него есть либо доступный инструмент изображений, либо выбранные вами локальные картинки. ADB и LabelGrid необязательны и на этом этапе не нужны.

## При следующем запуске на телефоне

**На каком я экране?** Если видите разговор с помощником, вы в Codex; нажмите Ctrl+C по подсказке, чтобы вернуться в командную строку. В командной строке выполните `cat /etc/os-release`. Если в ответе указана Ubuntu, вы уже внутри Ubuntu. Если файла нет, попробуйте `command -v pkg`: путь с `com.termux` означает, что вы в Termux. Если ни один признак не подходит, попросите помощи, а не входите в ещё одну среду Linux вслепую.

Откройте Termux. Если вы уже внутри Ubuntu, пропустите первую команду. Иначе выполните:

```sh
proot-distro login ubuntu --bind /storage/emulated/0:/storage/emulated/0
```

**Внутри Ubuntu**:

```sh
cd ~/projects/agentic-evangelism
codex
```

Команда `codex resume` позволяет выбрать предыдущий разговор. Чтобы выйти из Codex, нажмите Ctrl+C по подсказке; у Termux есть клавиша Ctrl в дополнительном ряду клавиш. В командной строке Ubuntu введите `exit`, чтобы вернуться в Termux. Переустанавливать всё при каждом запуске не нужно.
