# Choose your device

[Українська](../uk/setup.md) · [Русский](../ru/setup.md) · English

Choose the platform where you want to set up and run the skill:

- **[Android Phone](phone-setup.md)** — Run on your phone using Termux and PRoot Ubuntu. No computer needed.
- **[Windows PC](setup-windows.md)** — Run on Windows using PowerShell or Command Prompt.
- **[Mac (macOS)](setup-macos.md)** — Run on macOS using Terminal and Homebrew.
- **[Linux](setup-linux.md)** — Run on Ubuntu, Debian, Fedora, Arch, or a Linux server.

After completing setup for your platform, proceed to [making your first video](first-video.md).
