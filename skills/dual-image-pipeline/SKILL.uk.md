# Двовендорний швидкісний конвеєр генерації зображень

[English](SKILL.md) · [Русский](SKILL.ru.md) · [Українська](SKILL.uk.md)

Файл `SKILL.md` є встановленою точкою входу; цей файл — україномовний переклад того самого скіла. Цей скіл прискорює генерацію зображень для розкадровок TikTok-відео завдяки паралельній роботі **Antigravity (AGY / Gemini 3.1 Flash Image)** та **Codex (OpenAI GPT-Image 2.5)**, скорочуючи час пакетної генерації до лічених секунд.

## Архітектура та паралелізм

Під час підготовки вертикальних відео для TikTok за розкадровкою (наприклад, через `suno-tiktok-video`) послідовна генерація 8–12 сцен є головним вузьким місцем за часом. Двовендорний конвеєр усуває цю затримку, розподіляючи завдання одночасно у два незалежні пули:

1. **Пул Antigravity (`agy`)**: Паралельні запити до Gemini 3.1 Flash Image (оптимальний пул: 3–4 одночасні завдання). Нативна роздільна здатність 9:16 ($768 \times 1376$).
2. **Пул Codex (`codex`)**: Паралельні запити через Codex CLI / GPT-Image 2.5 Flare (оптимальний пул: 1–2 завдання). Нативна роздільна здатність 9:16 ($1024 \times 1792$).
3. **Автоматичний Failover**: Якщо один із вендорів стикається з обмеженням швидкості (HTTP 429), вичерпанням квоти або тимчасовим збоєм API, інший вендор автоматично підхоплює решту завдань без зупинки конвеєра.

Обидві нативні роздільності плавно масштабуються та центруються скриптом `build_video.py` у стандартний Full HD $1080 \times 1920$.

## Візуальні правила та стильовий якір

Щоб уникнути розбіжності візуального стилю між двома рушіями в межах одного відеокліпу:

- **Стильовий якір (Style Anchor)**: Єдиний структурований блок стилю (`Visual Bible`) додається до всіх промптів, фіксуючи оптику, колірну гаму та характер освітлення (наприклад, `cinematic 35mm photography, natural daylight, kodak portra tones, soft focus background`).
- **Візуальна подача за замовчуванням**: Відповідає принципам `evangelical_baptist`: Писання, молитва, християнське спілкування, діла служіння та Боже творіння. Не додаються німби, культові ікони, іконостаси, цибулясті бані та пізніші літургійні облачення. Явний вибір користувача (наприклад, `interdenominational_unity`) має пріоритет.

## Використання

Генерація всіх сцен розкадровки паралельно:

```sh
python3 scripts/generate.py --storyboard '/absolute/storyboard.json' --output-dir '/absolute/images'
```

Генерація поодинокого тестового кадру:

```sh
python3 scripts/generate.py --prompt 'Peaceful mountain valley at sunrise, wildflowers, soft golden morning light' --output '/absolute/scene-01.png' --aspect-ratio 9:16
```

Детальні специфікації вендорів, квоти та коди помилок описані в [references/providers.uk.md](references/providers.uk.md).
