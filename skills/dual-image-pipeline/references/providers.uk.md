# Довідник провайдерів генерації зображень

[English](providers.md) · [Русский](providers.ru.md) · [Українська](providers.uk.md)

У цьому документі описано технічні специфікації, нативні роздільні здатності, правила паралелізму та логіку фінансово-адаптивного перемикання (failover).

## 1. Antigravity (`agy` / Gemini Image)

- **Рушій**: Gemini 3.1 Flash Image.
- **Нативна роздільна здатність**:
  - Вертикальна (`9:16`): $768 \times 1376$ (~1.05 Мп, кратно патчам 16/32).
  - Горизонтальна (`16:9`): $1376 \times 768$.
  - Квадрат (`1:1`): $1024 \times 1024$.
- **Час генерації**: ~10–14 секунд на кадр.
- **Рекомендований паралелізм**: 3–4 одночасні запити у пачці.
- **Коди помилок**:
  - `429 / RESOURCE_EXHAUSTED`: Досягнуто ліміт частоти запитів або сесії. Викликає автоматичну передачу залишкових сцен у Codex або в безкоштовний рівень.

## 2. OpenAI Codex (`codex` / GPT-Image 2.5)

- **Рушій**: GPT-Image 2.5 Flare (оптимізовано для швидкості) та Sunburst.
- **Нативна роздільна здатність**:
  - Вертикальна (`9:16`): $1024 \times 1792$ (~1.83 Мп).
  - Горизонтальна (`16:9`): $1792 \times 1024$.
  - Квадрат (`1:1`): $1024 \times 1024$.
- **Час генерації**: ~12–18 секунд на кадр.
- **Рекомендований паралелізм**: 1–2 одночасні запити у пачці.
- **Коди помилок**:
  - `429 / rate_limit_exceeded`: Досягнуто хвилинний або ковзний ліміт підписки. Викликає автоматичну передачу залишкових сцен у AGY або в безкоштовний рівень.

## 3. Відкритий безкоштовний рівень (`free` / Pollinations FLUX)

- **Рушій**: FLUX.1 через відкритий ендпоінт Pollinations.ai.
- **Вартість**: **$0** (без підписок, без API-ключів, без банківських карток).
- **Нативна роздільна здатність**:
  - Вертикальна (`9:16`): $768 \times 1376$.
  - Горизонтальна (`16:9`): $1376 \times 768$.
  - Квадрат (`1:1`): $1024 \times 1024$.
- **Час генерації**: ~15–25 секунд на кадр.
- **Рекомендований паралелізм**: 1–2 одночасні запити.
- **Призначення**: Гарантує, що церковні волонтери, молодь та автори з будь-яким достатком можуть створювати повноцінні відеоролики для служіння без фінансових витрат.

## 4. Фінансово-адаптивна диспетчеризація

Для розкадровки з $N$ сцен:
- **Рівень 1 (Двовендорний)**: Сцени розподіляються між пулами: AGY обробляє пачку $A$, а Codex — пачку $B$.
- **Рівень 2 (Один вендор)**: Усі сцени спрямовуються в єдиний налаштований інструмент (`agy` або `codex`).
- **Рівень 3 (Нульовий бюджет)**: Активується автоматично за відсутності платних інструментів або явно прапорцем `--free`.
- У разі помилок лімітів завдання плавно переходять на наступний доступний рівень.
- Готові файли перевіряються на валідність заголовків зображень і зберігаються за шляхами, вказаними в розкадровці.
