# Параллельные иллюстрации для раскадровки

[English](SKILL.md) · [Русский](SKILL.ru.md) · [Українська](SKILL.uk.md)

Этот скилл организует создание независимых иллюстраций. Проверьте, какой инструмент изображений действительно доступен в среде. В Codex следуйте установленному скиллу `imagegen` и по умолчанию используйте встроенный `image_gen`. Установка этой папки не устанавливает сервис, не разрешает внешний API и не гарантирует доступ к двум провайдерам.

Задайте единый визуальный стиль и неизменное описание персонажа. Создайте и просмотрите стилевой образец, затем тестовый ракурс. После проверки отправляйте независимые сцены ограниченными параллельными пакетами. В режиме кода Codex запускайте по одному `tools.image_gen__imagegen({prompt})` для каждого объекта внутри `Promise.allSettled(assets.map(...))`. До отправки присвойте каждому объекту постоянный ID; сохраните промпт, инструмент, результат и путь по ID, а не по порядку завершения. Просмотрите каждое изображение, сохраняйте удачные и повторяйте только неудачные. Запишите настоящий маршрут в `storyboard.json` (например, `generation_mode: built_in_imagegen`) и ID объектов в каждом отправленном пакете, чтобы позднее можно было проверить способ генерации. Одновременная отправка не гарантирует одновременную обработку сервисом или фиксированную скорость.

Применяйте визуальную политику песни, по умолчанию `evangelical_baptist`: Писание, молитва, общение, служение и творение по смыслу текста. Исключайте нимбы, культовые иконы, иконостасы, луковичные купола и незапрошенные облачения. Уважайте явный выбор сцены, например `interdenominational_unity`. Сохраняйте иллюстрации рядом с раскадровкой, а не только в папке генератора.

`scripts/generate.py` — необязательный прежний маршрут CLI, а не встроенный инструмент Codex. `--dry-run` создаёт крошечные тестовые файлы, непригодные для видео. Для живого режима нужны `--allow-external-cli` и явное разрешение на выбранный внешний сервис; `--free` выбирает Pollinations, а `--allow-free-fallback` допускает его после ошибки другого провайдера. Перед запуском проверьте настоящую команду генерации, доступ к сети и действующую стоимость. Наличие `agy` или `codex` само по себе не доказывает доступность генерации. [Заметки о провайдерах](references/providers.ru.md) объясняют ограничения, а не цены.
