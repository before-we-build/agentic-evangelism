# Двухвендорный скоростной конвейер генерации изображений

[English](SKILL.md) · [Русский](SKILL.ru.md) · [Українська](SKILL.uk.md)

Файл `SKILL.md` является точкой входа; данный файл — русскоязычный перевод того же скилла. Этот скилл ускоряет генерацию изображений для раскадровок TikTok-видео за счёт параллельной работы **Antigravity (AGY / Gemini 3.1 Flash Image)** и **Codex (OpenAI GPT-Image 2.5)**, сокращая время пакетной генерации до считанных секунд.

## Архитектура и параллелизм

При подготовке вертикальных видео для TikTok по раскадровке (например, через `suno-tiktok-video`) последовательная генерация 8–12 сцен является главным «бутылочным горлышком» по времени. Двухвендорный конвейер устраняет эту задержку, распределяя задачи одновременно в два независимых пула:

1. **Пул Antigravity (`agy`)**: Параллельные запросы к Gemini 3.1 Flash Image (оптимальный пул: 3–4 одновременных задачи). Нативное разрешение 9:16 ($768 \times 1376$).
2. **Пул Codex (`codex`)**: Параллельные запросы через Codex CLI / GPT-Image 2.5 Flare (оптимальный пул: 1–2 задачи). Нативное разрешение 9:16 ($1024 \times 1792$).
3. **Автоматический Failover**: Если один из вендоров сталкивается с ограничением скорости (HTTP 429), исчерпанием квоты или временным сбоем API, второй вендор автоматически подхватывает оставшиеся задачи без остановки конвейера.

Оба нативных разрешения плавно масштабируются и центрируются скриптом `build_video.py` в стандартный Full HD $1080 \times 1920$.

## Визуальные правила и стилевой якорь

Чтобы исключить расхождение визуального стиля между двумя движками в рамках одного видеоклипа:

- **Стилевой якорь (Style Anchor)**: Единый структурированный блок стиля (`Visual Bible`) добавляется ко всем промптам, фиксируя оптику, цветовую гамму и характер освещения (например, `cinematic 35mm photography, natural daylight, kodak portra tones, soft focus background`).
- **Визуальная подача по умолчанию**: Соответствует принципам `evangelical_baptist`: Писание, молитва, христианское общение, дела служения и Божье творение. Не добавляются нимбы, культовые иконы, иконостасы, луковичные купола и позднейшие литургические облачения. Явный выбор пользователя (например, `interdenominational_unity`) имеет приоритет.

## Использование

Генерация всех сцен раскадровки параллельно:

```sh
python3 scripts/generate.py --storyboard '/absolute/storyboard.json' --output-dir '/absolute/images'
```

Генерация одиночного тестового кадра:

```sh
python3 scripts/generate.py --prompt 'Peaceful mountain valley at sunrise, wildflowers, soft golden morning light' --output '/absolute/scene-01.png' --aspect-ratio 9:16
```

Подробные спецификации вендоров, квоты и коды ошибок описаны в [references/providers.ru.md](references/providers.ru.md).
