# Текст → смислові частини → послідовність зображень

[English](storyboard.md) · [Русский](storyboard.ru.md) · [Українська](storyboard.uk.md)

До планування ілюстрацій прочитайте видобутий текст. Збережіть джерело, повторні куплети/приспіви та позначення частин. Видаляйте неспівані виробничі вказівки з робочої версії, не з джерела. Відсутній або суперечливий текст потрібно уточнити; назва й музичний стиль його не замінюють.

## Смисловий план

Визначте центральну думку й послідовні головні підтеми: протиставлення, конкретну ситуацію, питання, відповідь, емоційний поворот або розв’язання. Об’єднуйте сусідні рядки про одну думку; не перетворюйте кожен рядок на непов’язану картинку. Дайте підтемам постійні ID та короткий підтвердний уривок або посилання на рядки. Відокремлюйте зміст тексту від художньої метафори. Не вигадуйте відсутнє богослов’я, політичних дійових осіб чи події.

Кожна головна підтема отримує окреме зображення. Повторні приспіви можуть використовувати відповідні картинки знову; зберігайте кожну появу в послідовності, не видаляючи повторів тексту. Використовуйте узгоджену палітру, стиль і повторювані мотиви. Довгі частини можуть чергувати кілька пов’язаних композицій, щоб одна картинка не залишалася на хвилину. Кількість зображень і сцен різниться: одне зображення може з’являтися кілька разів.

## Приблизний ритм без позначок тексту

Використовуйте точну тривалість D із перевірки аудіо. Плануйте безперервні сцени від 0 до D без прогалин, зміни звуку й тверджень про синхронізацію зі словами. Спочатку розподіліть час між послідовними частинами пропорційно довжині тексту або оцінці кількості складів, якщо вона доступна. За наявності підстав окремо передбачте приблизні вступ, завершення та інструментальні частини. Це груба монтажна оцінка: швидкість співу, довгі ноти, повтори й програші можуть її порушувати. Позначайте її `editorial_estimate`; не стверджуйте, що прослухали або перевірили межі, якщо не звіряли з аудіо.

Як творчу відправну точку використовуйте зміну зображень приблизно кожні 8–15 секунд, повільніше в споглядальних частинах і швидше в енергійних. Це **місцевий монтажний орієнтир**, не виміряний оптимум TikTok і не жорстка межа. Довгі оцінні частини діліть на пов’язані ракурси або повторні зображення цієї підтеми; нова генерація для кожної зміни не обов’язкова. Перший кадр має бути відразу зрозумілим та емоційно пов’язаним із піснею. Не додавайте непов’язаний тизер, порожню заставку, що затримує початок, миготіння або беззмістовні склейки. Остання сцена має завершувати центральний образ пісні. Не додавайте рекламних закликів і не скорочуйте повну пісню автоматично.

Перед генерацією коротко повідомте тривалість, головні підтеми, кількість унікальних зображень і сцен, приблизний ритм. Продовжуйте в межах дозволеного запиту; не вводьте окреме погодження плану. За незвично великої кількості зображень або явних обмежень часу/вартості адаптуйте план і поясніть компроміс.

## Файл плану

Збережіть JSON поряд з ілюстраціями. Приклад для умовної пісні на 20 секунд: замініть тривалість, текст і шляхи справжніми. Технічні ключі JSON не перекладаються.

```json
{
  "timing_basis": "editorial_estimate_no_lyric_alignment",
  "lyrics_source": "lyrics.json",
  "central_message": "Надія в невизначеності",
  "subideas": [
    {"id": "uncertainty", "summary": "Мить сумніву", "evidence": "рядки 1–4 робочого тексту"},
    {"id": "hope", "summary": "Відповідь із надією", "evidence": "рядки 5–8 робочого тексту"}
  ],
  "assets": [
    {"image": "art/01.png", "subidea_id": "uncertainty", "prompt": "Справжній повний промпт генерації"},
    {"image": "art/02.png", "subidea_id": "hope", "prompt": "Справжній повний промпт генерації"}
  ],
  "scenes": [
    {"subidea_id": "uncertainty", "image": "art/01.png", "duration_seconds": 8.0},
    {"subidea_id": "hope", "image": "art/02.png", "duration_seconds": 12.0}
  ]
}
```

Збирач використовує `scenes[].image` і `scenes[].duration_seconds`; решта полів дозволяє агенту й користувачеві простежити смислові рішення. Шляхи абсолютні або відносно цього JSON. Початок сцени — сума попередніх тривалостей. Уточніть останню тривалість, щоб сума дорівнювала D. Перевірте збережене зображення для кожної підтеми й усі заплановані повторення. Не називайте цю приблизну послідовність субтитрами або караоке.
