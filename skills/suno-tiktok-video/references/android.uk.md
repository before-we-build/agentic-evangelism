# Зробити готове відео видимим на Android

[English](android.md) · [Русский](android.ru.md) · [Українська](android.uk.md)

Використовуйте лише дозволений під’єднаний пристрій. Запустіть `adb devices`; явно виберіть потрібний пристрій через `-s SERIAL`. Якщо пристроїв кілька й вибір неясний, уточніть. Не використовуйте стару бездротову адресу: вона змінюється.

Перевірте файл на телефоні, а не лише всередині PRoot. Приклади передбачають просте ім’я латиницею, підготовлене скілом:

```sh
adb -s SERIAL shell ls -l /storage/emulated/0/Download/TikTok_peace.mp4
adb -s SERIAL shell am broadcast -a android.intent.action.MEDIA_SCANNER_SCAN_FILE -d file:///storage/emulated/0/Download/TikTok_peace.mp4
adb -s SERIAL shell content query --uri content://media/external/video/media --projection _id:_display_name:relative_path --where "\"_display_name='TikTok_peace.mp4'\""
```

Успішна розсилка команди сама собою не доводить індексацію. Підтвердьте рядок відповіді з потрібним ім’ям і `relative_path=Download/`. Для інших імен правильно екрануйте аргументи оболонки Android і кодуйте URI файлів; не вставляйте довільні імена в команди. Прості імена ASCII дозволяють уникнути цієї крихкої операції.

Підтримка розсилки й дозволи залежать від версії Android. Якщо запит спочатку не повернув рядок, трохи зачекайте й повторіть один раз. Якщо файла досі немає, повідомте, що індексацію не підтверджено, і вивчіть помилку; не повторюйте нескінченно й не змінюйте системні дозволи.

Якщо файл проіндексовано, але список вибору застарів: закрийте й заново відкрийте його, виберіть «Відео» або «Огляд» → внутрішня пам’ять → Download і знайдіть точне ім’я. Уточнюйте вигляд вікна вибору лише якщо ці дії не допомогли. Без ADB знайдіть і відкрийте MP4 у застосунку «Файли» та знову відкрийте вибір. Рядок MediaStore не доводить публікацію або успішне завантаження назовні.

Практичний висновок: наявність файла й правильні кодеки ще не доводять його видимість у виборі. Коротке ім’я спрощує пошук; сканування додає запис до бібліотеки Android. Саме лише кириличне ім’я не доводить причину проблеми з видимістю.
