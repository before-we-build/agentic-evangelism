# Подготовка и проверка видео на Windows

[English](windows.md) · [Русский](windows.ru.md) · [Українська](windows.uk.md)

На Windows команды выполняются в PowerShell, командной строке (CMD), Git Bash или WSL.

## Загрузки и расположение файлов

По умолчанию исходная аудиозапись ищется в папке «Загрузки» (Downloads):
- Автоматически определяется через `platform_utils.py` с использованием стандартного Win32 Known Folder `FOLDERID_Downloads`.
- Запасной путь: `%USERPROFILE%\Downloads` (например, `C:\Users\<имя_пользователя>\Downloads`).
- Если вы используете WSL, доступ к Загрузкам Windows осуществляется через `/mnt/c/Users/<имя_пользователя>/Downloads`.

## Пути и кодировки

- При передаче путей с пробелами или не-ASCII символами в PowerShell или CMD заключайте их в кавычки.
- В скриптах Python пути обрабатываются через `pathlib.Path`, который корректно воспринимает как прямые, так и обратные слэши.
- Вывод FFmpeg и ffprobe читается с явным указанием кодировки UTF-8.

## Запуск пайплайна

Проверьте готовность инструментов перед рендерингом:

```sh
python scripts/doctor.py
```

Сборка видео из аудиозаписи и раскадровки:

```sh
python scripts/build_video.py --audio "C:\Users\username\Downloads\song.mp3" --storyboard "C:\workspace\storyboard.json" --output "C:\Users\username\Downloads\TikTok_song.mp4"
```

## Доступность и ручная публикация

Готовый проверенный MP4-файл сохраняется по указанному пути (по умолчанию в вашу папку «Загрузки»).

- Скилл никогда не публикует видео автоматически.
- Откройте браузер и перейдите на страницу [tiktok.com/upload](https://www.tiktok.com/upload).
- Нажмите **Выбрать видео** (Select video) и выберите созданный MP4-файл из папки «Загрузки».
- Добавьте описание, проверьте предпросмотр и опубликуйте вручную.
