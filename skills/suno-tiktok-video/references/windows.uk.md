# Підготовка та перевірка відео на Windows

[English](windows.md) · [Русский](windows.ru.md) · [Українська](windows.uk.md)

На Windows команди виконуються в PowerShell, командному рядку (CMD), Git Bash або WSL.

## Завантаження та розташування файлів

За замовчуванням вихідний аудіозапис шукається в папці «Завантаження» (Downloads):
- Автоматично визначається через `platform_utils.py` за допомогою стандартного Win32 Known Folder `FOLDERID_Downloads`.
- Запасний шлях: `%USERPROFILE%\Downloads` (наприклад, `C:\Users\<ім'я_користувача>\Downloads`).
- Якщо ви використовуєте WSL, доступ до Завантажень Windows здійснюється через `/mnt/c/Users/<ім'я_користувача>/Downloads`.

## Шляхи та кодування

- Під час передачі шляхів із пробілами або не-ASCII символами в PowerShell чи CMD огортайте їх у лапки.
- У скриптах Python шляхи обробляються через `pathlib.Path`, який коректно сприймає як прямі, так і зворотні слеші.
- Вивід FFmpeg та ffprobe зчитується з явним зазначенням кодування UTF-8.

## Запуск пайплайну

Перевірте готовність інструментів перед рендерингом:

```sh
python scripts/doctor.py
```

Збирання відео з аудіозапису та розкадровки:

```sh
python scripts/build_video.py --audio "C:\Users\username\Downloads\song.mp3" --storyboard "C:\workspace\storyboard.json" --output "C:\Users\username\Downloads\TikTok_song.mp4"
```

## Доступність і ручна публікація

Готовий перевірений MP4-файл зберігається за вказаним шляхом (за замовчуванням у вашу папку «Завантаження»).

- Скіл ніколи не публікує відео автоматично.
- Відкрийте браузер і перейдіть на сторінку [tiktok.com/upload](https://www.tiktok.com/upload).
- Натисніть **Вибрати відео** (Select video) та виберіть створений MP4-файл із папки «Завантаження».
- Додайте опис, перевірте попередній перегляд і опублікуйте вручну.
